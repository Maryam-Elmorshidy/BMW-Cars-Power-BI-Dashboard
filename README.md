# BMW Cars | Interactive Power BI Dashboard

An interactive Power BI project showcasing five BMW models: **X1, X3, X5, X6, and M3**.

The project focuses on dashboard design, data visualization, and interactive navigation, providing a consistent and user-friendly experience for exploring different BMW models.

---

## Project Overview

The dashboard includes five dedicated pages, one for each BMW model. Each page presents the available data through visual elements and interactive features, with a focus on clarity, visual consistency, and ease of navigation.

## BMW Models

- BMW X1
- BMW X3
- BMW X5
- BMW X6
- BMW M3

## Tools & Features

- **Tool:** Microsoft Power BI
- Bookmarks
- Page Navigation
- Buttons
- Selection Pane
- Interactive navigation between report pages
- Visual display of available car colors
